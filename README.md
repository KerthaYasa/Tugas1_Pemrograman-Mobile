## 📋 Deskripsi Aplikasi

Aplikasi ini merupakan tugas pertama mata kuliah Pemrograman Mobile yang dibuat menggunakan **Android Studio**. Aplikasi menampilkan kartu profil mahasiswa dengan fitur sapaan interaktif.

---

## ✨ Fitur

- 👋 **Tampilan Profil** — Menampilkan foto, nama, NIM, dan jurusan
- 🌍 **Hello World** — Teks sambutan bold dan menarik di bagian atas
- 💬 **Tombol Sapa** — Menampilkan pesan sambutan ketika ditekan
- 🔄 **Tombol Reset** — Menyembunyikan pesan kembali
- 📱 **Responsive** — Menggunakan ScrollView agar tampil baik di semua ukuran layar

---

## 🛠️ Teknologi yang Digunakan

- **Language**: Java / Kotlin
- **IDE**: Android Studio
- **Min SDK**: Android 7.0 (API 24)
- **UI**: XML Layout (LinearLayout + ScrollView)
- **Theme**: Material Components

---

## 🚀 Cara Menjalankan

1. Clone repository ini:
   ```bash
   git clone https://github.com/KerthaYasa/Tugas1_Pemrograman-Mobile.git
   ```

2. Buka project di **Android Studio**

3. Tunggu Gradle sync selesai

4. Jalankan di emulator atau perangkat fisik dengan menekan tombol **▶ Run**

---

## 📁 Struktur Project

```
app/

        │   ├── values/     # strings.xml, themes.xml, colors.xml
```
